# 🎵 Audio Visualizer Studio

> Browser-basierter Musik-Visualizer mit Echtzeit-Analyse und Video-Export
<img width="2880" height="3846" alt="screenshot" src="https://github.com/user-attachments/assets/e5893d68-4ebf-4b58-9f33-705203e80756" />

## ✨ Features

- 15+ Visualizer-Modi (Radial, Waterfall, LED EQ, Lissajous Scope...)
- Echtzeit Beat-Detection
- Logo & Text Overlay mit Drag & Drop
- Direkte Video-Aufnahme (WebM, VP9, bis 12 Mbps)
- Hintergrundbilder mit Reaktions-Effekten
- Partikel-System
- Läuft komplett im Browser – keine Installation nötig

## 🛠️ Tech Stack

`Web Audio API` `Canvas 2D` `MediaRecorder API` `Vanilla JavaScript` `CSS Grid`

## 🚀 Nutzung

Einfach `index.html` im Browser öffnen – fertig. Keine Installation, kein Server.
